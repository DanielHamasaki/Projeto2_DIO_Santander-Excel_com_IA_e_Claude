# 📊 Organizador de Declaração de Imposto de Renda

Este repositório contém o projeto desenvolvido para o desafio **"Criando um Organizador de Declaração de Imposto de Renda"**, parte integrante do Bootcamp **Santander 2026 - Planilhas Inteligentes com IA**, oferecido pela [DIO (Digital Innovation One)](https://web.dio.me/).

## 🎯 Sobre o Projeto

O objetivo deste projeto foi criar uma ferramenta no Excel para facilitar e automatizar a organização dos dados necessários para a Declaração do Imposto de Renda Pessoa Física (IRPF). 

O grande diferencial deste desafio é a aplicação prática de **Inteligência Artificial** na construção da solução. A IA (especificamente o Claude) foi utilizada como assistente para estruturar os dados, sugerir categorias, criar fórmulas eficientes e otimizar o layout da planilha, demonstrando como a tecnologia pode acelerar tarefas burocráticas do dia a dia.

## 📁 Arquivo do Projeto

O resultado final do desafio está consolidado no seguinte arquivo:
* 📄 `Projeto2_IR_DIO_Santander-Excel_com_IA_e_Claude.xlsx`

## 🛠️ Tecnologias e Ferramentas Utilizadas

*   **Microsoft Excel:** Utilizado para a criação da interface, tabelas dinâmicas, formatações condicionais e cálculos automatizados.
*   **Inteligência Artificial (Claude):** Utilizada como apoio de co-piloto para:
    *   Planejamento da estrutura das abas da planilha.
    *   Geração de categorias de rendimentos e despesas dedutíveis.
    *   Resolução de problemas lógicos e criação de fórmulas complexas.
*   **Engenharia de Prompts:** Técnicas aplicadas para extrair os melhores resultados da IA durante o desenvolvimento.

## ⚙️ Funcionalidades da Planilha

A planilha `Projeto2_IR_DIO_Santander-Excel_com_IA_e_Claude.xlsx` foi estruturada para conter as principais categorias exigidas pela Receita Federal, como:

1.  **Rendimentos:** Controle de salários, pró-labore, aluguéis recebidos e rendimentos isentos/não tributáveis.
2.  **Despesas Dedutíveis:** Organização de gastos com saúde, educação, previdência privada, pensão alimentícia, entre outros.
3.  **Bens e Direitos:** Registro de imóveis, veículos, saldos bancários e investimentos.
4.  **Dívidas e Ônus Reais:** Controle de empréstimos e financiamentos.
5.  **Resumo/Dashboard:** Uma visão geral consolidada para facilitar a transcrição dos dados para o programa gerador da Receita Federal.

## 🚀 Como Utilizar

1.  Faça o download do arquivo `Projeto2_IR_DIO_Santander-Excel_com_IA_e_Claude.xlsx`.
2.  Abra o arquivo no Microsoft Excel (recomenda-se a versão mais recente para total compatibilidade).
3.  Navegue pelas abas inferiores para preencher seus dados financeiros referentes ao ano-base.
4.  Utilize o resumo consolidado para preencher a sua declaração oficial no software da Receita Federal.

> **⚠️ Aviso Legal:** Esta planilha é uma ferramenta de organização pessoal e educacional. Ela não substitui a consulta a um contador profissional nem se conecta automaticamente aos sistemas da Receita Federal.
